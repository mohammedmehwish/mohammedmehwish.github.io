# Mohammed Mehwish V M — Robotics & Mechatronics Engineer Portfolio

A premium, modern, production-ready personal portfolio website for **Mohammed Mehwish V M**, a Robotics, Mechatronics, and Embedded Systems Engineer based in Kerala, India.

Built with **React**, **Vite**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **Lucide Icons**, **HTML5 Canvas**, and **GitHub REST API**.

---

## 🚀 Live Demo & Features

- **Futuristic HUD Aesthetics**: Glassmorphism, animated circuit board trace lines, dynamic canvas particle network, dark/light theme toggle, and micro-interactions.
- **Hero Typing Animation**: Dynamically cycles through engineering roles (*Robotics Engineer*, *Embedded Systems Engineer*, *Computer Vision Enthusiast*, *Automation Engineer*).
- **GitHub REST API Integration**:
  - Live repository stats (Stars, Forks, Languages, Last Updated dates)
  - Dedicated **GitHub Page Section** with repository search, language filter, and sorting
  - Contribution heatmap graph visualization and top language breakdown chart
  - Graceful fallback mechanism if API rate limits are reached
- **Featured Projects**:
  - **Helmet Detection using Deep Learning**: Python, OpenCV, YOLO, PyTorch
  - **Fire Rescue Robot**: Embedded C, Arduino, ESP32, Sensors, Actuators
  - **Fire Rescue & Surveillance Drone**: Flight Controller, ESP32, Telemetry, OpenCV
  - Full-screen project details modal with deep-dive technical specs
- **Interactive Resume & Certifications**:
  - Downloadable PDF resume generator/file downloader
  - Certificate modal previewer with verified credentials
- **GitHub Pages Ready**: Includes automated GitHub Actions workflow (`.github/workflows/deploy.yml`) for seamless deployment.

## 💻 Local Setup Instructions

### Prerequisites
Make sure you have Node.js (v18+) and npm installed on your machine.

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The production bundle will be generated in the `dist/` directory.

## ⚙️ GitHub Pages Automatic Deployment

This repository includes a GitHub Actions workflow that deploys automatically whenever you push to the `main` or `master` branch.

### How to Enable GitHub Pages:
1. Push this project to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Mohammed Mehwish portfolio"
   git branch -M main
   git remote add origin https://github.com/mohammedmehwish/mohammedmehwish.github.io.git
   git push -u origin main
   ```
2. On GitHub, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. The workflow in `.github/workflows/deploy.yml` will automatically build and publish your portfolio!
